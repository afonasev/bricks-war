# Soft Toy SFX provenance

- Source pack: **Bub Block Sound Effects**
- Author: **roppychop / Roppy Chop Studios**
- Source: https://opengameart.org/content/bub-block-sound-effects
- License: **CC0 1.0 Universal**
- License text: https://creativecommons.org/publicdomain/zero/1.0/

The Soft Toy runtime subset contains `pickup.wav`, `open.wav`, `close.wav`, and
`drop1.wav` through `drop5.wav`. These files were converted from the source
pack's WAV recordings to mono 44.1 kHz PCM and loudness-normalized for the
game's existing Effects bus. The complete Soft Toy event registry derives its
coherent UI and gameplay variants from this audited physical-recording subset;
no other files from the source pack are bundled in the runtime.

Attribution is not required by CC0. This manifest is retained for asset
provenance and release auditing.
